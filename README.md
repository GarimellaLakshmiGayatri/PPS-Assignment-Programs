# PPS-Assignment-Programs
About


This repository contains my C programming assignment programs for Problem Solving and Programming(PPS).


PROGRAMS Included


 1.SIGNOFNUMBER.c - Checks whether a number is positive, negative, or zero.

2. RECTANGLEA&P.c - Calculates the area and perimeter of a rectangle.
 
3. VOTECHECK.c -Checks whether a person is eligible to vote.
 
4. LOANAPPROVAL.c - Checks whether a loan can be approved.
 
5. USERPASSWORD.c - Validates user ID and password.
 
6. STUDENTGRADE.c - Displays a student's grade based on marks.
 
7. BMI.c - Calculates BMI and displays the category.
 
8. VOWELORNOT.c - Checks whether a character is a vowel or not
    

Language Used

* C Programming
  
Tools Used

* Dev-C++
  
Purpose

To practice C programming concepts such as variables, input/output statements, operators, and conditional statements(if,else if, and else).
